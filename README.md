# 🍕 Pizza Project

A simple and interactive desktop application built with **Windows Forms** for customizing and ordering pizza.  
The application allows users to choose the pizza size, toppings, crust type, and dining option while displaying a live order summary and calculating the total price automatically.

---

## 📌 About the Project

**Pizza Project** is a beginner-friendly desktop application designed to practice event-driven programming, UI controls, form handling, and basic pricing logic in a Windows desktop environment.

The user can customize a pizza order through a clean graphical interface, review the selected options, confirm the order, or reset the form to start again.

---

## ✨ Features

- 🍕 Select pizza size:
  - Small
  - Medium
  - Large

- 🧀 Choose multiple toppings:
  - Extra Cheese
  - Mushrooms
  - Tomatoes
  - Onions
  - Olives
  - Green Peppers

- 🥖 Choose crust type:
  - Thin Crust
  - Thick Crust

- 🍽️ Select dining option:
  - Eat In
  - Take Out

- 💰 Automatic total price calculation
- 📋 Live order summary update
- ✅ Order confirmation message
- 🔒 Disable order options after confirmation
- 🔄 Reset form to default options

---

## 🖥️ Application Screens

The application includes a simple desktop UI where users can customize their pizza order and instantly see the selected options and total price.

Main sections include:
